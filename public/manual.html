飛行記録 PWA マニュアル

アプリを開く

ドローンの飛行前点検、離着陸地点、飛行後点検を、スマートフォンの中に残すアプリです。記録の正本は、いま開いている端末です。外へ自動で残すのは GoogleDrive自動バックアップだけで、送るのは「5.データ登録」のあと、オンのときです。項目を直しただけでは書き出しません。手動で残すときは、その場で選んだ場所へ出します。

アプリは最新バージョンを使ってください。版は画面上部の右端に出ます。

1. はじめに

開く

スマートフォンのブラウザで https://nagakiyo3821.github.io/flight-pwa/ を開きます。

通信できる状態で一度開くと、その後は電波が弱い場所でも点検を入力できます。気象の取得、住所の検索、地図、Google への書き出しと取り込みには通信が必要です。

位置情報は、離陸・着陸の登録と気象セットで使います。ブラウザ、またはホーム画面に追加したアプリに、位置情報を許可してください。

ホーム画面に置く

毎回 URL を探さなくて済み、全画面で使えます。

iPhone（Safari）

  1. Safari でアプリを開く（Chrome からは追加できません）。
  2. 共有ボタンを押し、「ホーム画面に追加」を選ぶ。
  3. 名前は「飛行記録」のままで追加する。
  4. 以降はホーム画面のアイコンから開く。

Android（Chrome）

  1. Chrome でアプリを開く。
  2. メニューの「アプリをインストール」または「ホーム画面に追加」を選ぶ。
  3. 以降はアイコンから開く。

ホーム画面のアイコンは、そのアイコン専用の保存領域を持ちます。飛行記録、場所、Google のフォルダはここに残ります。iPhone では、Safari の「履歴とWebサイトデータを消去」ではこの領域は消えません。保存領域ごと消すときは、アイコンを削除して、Safari からもう一度追加します。消したあとは、利用条件のあとホームから始まります。

最初に出るもの

利用条件の同意のあと、フォルダ選択は出ません。飛行記録と場所は、ファイルを取り込むまで空です。サンプルデータは自動では入りません。記録が残っているときは、閉じてもう一度開くと前回の続きからです。

ファイルを取り込まなくても飛行は始められます。飛行目的、飛行条件、障害物、正常／異常、機種名（Mavic2Pro / Tello / Other）は最初から入っています。氏名と機体の識別番号は、そのつど入力できます。毎回使う値は、あとから masters に入れておくと選択だけになります。

2. ホームと 1 回の飛行

ホーム

上の 4 つは、いつでも開けます。

ボタン用途
データリセット作業中の記録を空に戻し、続けて現在地の気象を入れ直す
システム設定マニュアル、中のデータの確認、GoogleDrive自動バックアップ、手動の書き出しと取り込み、初期化、利用条件
登録データ管理過去の飛行と、いま作業中の記録を開いて直す
場所データ管理離着陸地点の一覧、新規、修正、削除

その下の 1〜5 が、1 回の飛行の順番です。

表示意味
≫ と「設定待ち」または「時間場所設定」いまやる段
✓ と「修正可能」または「場所のみ更新」入力済み。開き直して修正できる
色が薄く「ロック中」手前の段が終わるまで開けない

タイトルの下の SR / SS / T:

  • SR … 日の出（気象セットで入る）
  • SS … 日の入
  • T … 最後に気象をセットした時刻からの経過秒。離陸時刻ではない

T が空のあいだは、経過の催促は出ません。

始める前（データリセット）

新しい飛行では、ホームの「データリセット」を押します。

  1. 確認で「リセット」を選ぶと、作業中の記録が空の NEW に戻ります。
  2. 「現在地の気象データをセットしますか？」で「セット」を選びます。
  3. 位置情報を許可し、現在地が取れると、天候、降水確率、風向、風速、気温、日の出、日の入が入ります。
  4. この時刻が T の起点です。

位置の入力をやめると、気象セットは中止されます。通信に失敗したときもセットされません。点検画面の「データセット」からやり直せます。

セットから 2 時間を超えてホームを開くと、気象の入れ直しを求められます。24 時間を超えると、リセットして入れ直すことを求められます。「後で」も選べます。

1. 離陸前チェック

ロックが外れている「1.離陸前チェック」を開きます。項目は次の塊です。

  • 環境 … 機種と識別番号、操縦者、体調、許可証・飛行日誌、安全運航管理者、飛行目的、飛行条件、障害物、第三者
  • 気象 … 天候、降水、風、気温（セット済みなら値が入っている）
  • 作動前・作動・飛行点検 … 取付、プロペラ、電源、バッテリー、リモート ID、GNSS、高度・距離の制限、灯火、カメラ、異音、スティック
  • 行を押すとその項目だけ開く
  • 全項目 … 表示中の項目を先頭から順に確認する
  • ?項目 … 空の項目だけ順に開く
  • データセット … 現在地の気象を入れ直す（ほかの項目は消えない）
  • 説明の末尾の (?) は未入力、(値) は入力済み
  • 「正常 / 異常」は 2 択。飛行条件は複数選べます
  • リストに無い氏名、バッテリー番号、機体の識別番号は「任意の入力」から追加できます
  • 屋内を飛行条件に含めると、GNSS 捕捉数と地上風向は空でも次へ進めます
  • 機種によっては最初から出ない項目があります（例: Tello のバッテリー詳細）

必須が埋まると、ホームで 1 が ✓ になり、2 が開きます。備考（項目 63）は空でも登録できます。

2. 離陸登録

「2.離陸登録」を開くと、地図で地点を決めます。緯度、経度、高度、住所、場所名は、この 1 画面でまとめて入ります。場所名は masters の一覧には無く、ここか「場所データ管理」で付けます。

  • 青 … いまの GPS。位置そのものは動かせません。「再GPS計測」で取り直します
  • 橙 … 記録する地点。地図をタップして動かせます。青や緑からコピーもできます
  • 緑 … いちばん近い登録済みの場所

橙を登録地点として確定すると、地点と離陸日時が記録されます。はじめての場所名なら場所一覧にも残ります。同名があるときは上書き確認が出ます。

緑と橙がおよそ 50m 以上離れているときは、橙を緑へ寄せる操作は使えません。別の場所として扱います。

一度時刻まで入ったあと、同じ段が「場所のみ更新」のときは、場所だけ直し、離陸時刻は維持します。画面を閉じると「離陸登録をキャンセルしました」となり、記録は変わりません。

3. 着陸登録

飛び終わったら「3.着陸登録」です。画面の意味は離陸と同じで、入るのは着陸側の地点と着陸日時です。飛行時間は離陸日時と着陸日時から計算します。

4. 着陸後チェック

着陸後のバッテリー、取付、汚れ、プロペラ、フレーム、発熱、操縦装置の電池、備考を入力します。やり方は離陸前チェックと同じです。

5. データ登録

「5.データ登録」で確定します。確認のあと、記録の名前が離陸日時（年/月/日 時:分）になります。作業用の空に近い NEW が残り、次の飛行の下書きになります。

離陸日時が空のままでは登録できません。登録すると工程は離陸前チェックに戻り、登録済みの内容は「登録データ管理」に残ります。

GoogleDrive自動バックアップがオン（ログイン済みで、自動用フォルダがある）なら、このとき log pos tmp mst を、そのドライブのフォルダへ、その時刻の新しいファイルとして送ります。ドライブへ書けなくても、端末の登録は取り消されません。起動したときや、通信が戻っただけでは送りません。

3. 場所

離陸と着陸の地点は、その場の GPS から記録します。同じ場所でも GPS は数メートルから数十メートルずれるので、登録地点には場所名と位置精度を付けます。登録地点を中心にした円の内側は、同じ場所です。円の半径が POSAC です。空のときは 15m です。高度のずれは ALTAC（空なら 5m）で見ます。境界線の上は円の外です。

  • 円の内側で「最寄地点確定」 … 登録してある緯度、経度、高度、住所、場所名に統合して記録します。
  • 円の外 … 別の場所です。住所から新しい名前を付け、位置精度 15m、高度精度 5m で追加します。
  • 円の内側で「タップ地点確定」 … 登録地点の座標は動かさず、今回の点を別名で残します。名前は 自宅屋上_0 のように、元の名前へ番号を足します。
  • 位置精度を広げると、より広いぶれを同じ場所に吸収できます。狭めると、少し離れた点は別場所になります。
  • 緑（登録地点）と橙（今回の点）がおよそ 50m 以上離れているときは、橙を緑へ寄せる操作は使えません。

飛行の前に場所を登録しておくと、次の離陸・着陸からこの統合が使えます。登録が無い状態でも GPS での記録はでき、確定した場所がこの一覧に残ります。

「場所データ管理」では次ができます。

  • 新規場所登録 … 地図で地点を決めて名前を付ける
  • 一覧の行 … 名前、住所、緯度、経度、高度、位置精度、高度精度を直す。削除もここから

4. 記録を直す

ホームの「登録データ管理」は、記録の一覧です。新しいものが上です。作業中の NEW（と NEW に日時が付いたもの）が先頭に来ます。

行を開くと、項目 1〜63 を直接直せます。離陸地点（項目 43〜47）と着陸地点（項目 48〜52）は、それぞれ地図の 1 画面です。場所名だけを文字で足す欄はありません。

  • 作業中（NEW）には、削除、データ登録、データリセット、データセット、離陸、着陸、全項目、?項目があります
  • 本登録済みの記録には、削除、全項目、?項目があります。離陸日時を変えると、新しい日時の記録が追加され、古いキーの記録も残ります
  • 削除は確認のあと、その 1 件だけ消します

5. システム設定

上から、操作設定方法、PWA内部データ編集、GoogleDrive自動バックアップ、手動エクスポート、手動インポート、PWA初期化、利用条件です。

GoogleDrive自動バックアップ

保管先は、この端末で選んだマイドライブのフォルダです。自動用と手動用は別々に覚えます。「フォルダ変更」のあと、マイドライブ上のパス（例: drone/data）を探します。無いフォルダは作りません。同じ名前が複数あるときは、どれかを選びます。

動作中になるのは、ログインできていて、自動用フォルダが決まっているときです。画面を開いただけでは動作中になりません。「動作」はフォルダが決まっているときだけ押せます。「停止」を押すと停止中になり、ログインは切れ、フォルダは残ります。もう一度「動作」を押すまで停止中です。

フォルダを変えたときは、その時点で tmp.json を自動用フォルダへ書きます。ログイン済みで自動用フォルダがあるときに書きます。「動作」「停止」と、手動エクスポートでは、この自動の書き出しはしません。

手動で書き出す・取り込む

ボタンは端末で名前が変わります。iPhone は「iPhone/iCloud」と「GoogleDrive」、Android は「Android」と「GoogleDrive」、パソコンは「パソコン」と「GoogleDrive」です。前回のフォルダ名は出しません。押したあと、log pos mst tmp を選びます。はじめはすべてオフです。1 つも選ばないと「1つ以上選んでください。」と出ます。

書き出すファイル名は log_20261014201245.json のように、種類、アンダースコア、書いた年月日時分秒です。1 回の書き込みでは、選んだ種類すべてが同じ 14 桁になります。masters のファイル名は mst_ です。日時の無い log.json や masters.json は、日時付きより古い版として読みます。旧ショートカットの log03.json のように末尾に番号が付いたファイルも、中身が同じ形式なら取り込めます。

  • パソコンと、フォルダを覚えられる Android … 書き出しは、選んだ種類を日時付きの新しいファイルとしてそのフォルダへ出します。取り込みは、種類ごとにフォルダ内のいちばん新しいファイルを読みます。個別のファイル名は選びません。
  • iPhone の書き出し … 実行のあと共有が開き、「ファイルに保存」でフォルダを選びます。
  • iPhone の取り込み … そのつどフォルダを選び、中のいちばん新しいファイルを読みます。
  • GoogleDrive … マイドライブ以降のフォルダ名を入力します。書き出しは日時付きの新しいファイルを追加します。飛行記録の取り込みは、いちばん新しいファイルを読み、同じ記録は端末側を残し、ドライブにしか無い分を足します。

フォルダからの取り込みは、選んだ種類で端末側を置き換えます。混ぜて編集したいときは、先にいまのデータを書き出してください。tmp の取り込みは、作業の進みと、入っていれば Google の自動フォルダを戻します。ログインは戻りません。

結果は、書いたファイル名、または読んだファイル名を 1 行で示します。処理中は他の操作を選べません。通信が止まったときは、時間内に終わらなかった旨を出して操作を戻します。

少なくとも log pos mst を残すと、別の端末へ引き継げます。自動フォルダも渡すときは tmp も選びます。

中のデータを直す

「PWA内部データ編集」のボタンは log.json pos.json mst.json tmp.json です。

ボタン開くもの
log.json登録データ管理
pos.json場所データ管理
mst.json点検の選択肢。行は「番号.項目名」「キー」「値」
tmp.json作業の進み、気象セット時刻、自動フォルダ

mst.json と tmp.json は、値が 1 つのときは修正値に現状値が入り、消去と元へ戻すが使えます。値が複数のときは一覧になり、選んだ値の修正、前や末尾への追加、削除ができます。機種名の行を開くと、その機種の識別番号と、出さない点検項目が続きます。

任意入力の文言は、氏名、バッテリー番号、機体の識別番号の 3 つです。それぞれ氏名の一覧、バッテリー番号の一覧、機種の一覧に付きます。場所名の文言はここにありません。古い mst に「任意の場所名の入力」が残っていても、起動時に除きます。

初期化する

「初期化」を押し、log pos tmp mst を選んで実行します。はじめはすべてオフです。飛行記録は空の NEW に、masters は初期の選択肢に戻ります。tmp を選ぶと、作業の進みと GoogleDrive自動バックアップのフォルダを未設定に戻します。ログインは残ります。ドライブやフォルダにあるファイルは消えません。

Google のログイン

公開ステータスは「テスト中」です。ログインできるのは、テストユーザーに登録した Google アカウントだけです。

「動作」、または手動の Google を押したあと、「このアプリは Google で確認されていません」と出ることがあります。詳細 を開き、（安全ではないページ）に移動 を選んでから、ドライブへの許可を出します。テスト中はログインのたびにこの画面になります。

ログインは、そのブラウザを開いているあいだ残り、およそ 1 時間で切れます。アプリを開き直したあとや切れたあとは、もう一度「動作」を押します。別のアカウントを使うときは、Cloud Console のテストユーザーへそのアドレスを追加します。上限は 100 人です。トークンは人に渡さず、リポジトリにも置きません。

6. ファイルの中身

出し入れするファイルは 4 つです。拡張子は .json です。値はすべて文字です。数値も "15" のように文字で入ります。ログインのトークンと、フォルダへの書き込み許可は入りません。手動の Google フォルダは毎回指定するので、ファイルには残りません。古い settings.json を取り込むときは、中の googleAuto だけを tmp.json へ戻します。

状況対処
ボタンがロック中手前の段の必須項目を埋める。場所の段なら離陸前、着陸後なら着陸登録
気象が入らない通信と位置情報を確認し、「データセット」をやり直す
地図が出ない通信できる場所で開く。地図は国土地理院のタイルです
氏名や機種が出てこないmasters を取り込んだか、別のブラウザで開いていないかを確認する
別の端末に記録が無い書き出した log / pos / mst を、その端末の「手動インポート」で読む
記録が消えたサイトデータの削除や、別ブラウザで開いています。外に書き出したファイルから取り込みます
再起動してもフォルダが残るホーム画面のアイコンから開いているときは、Safari の履歴消去では消えません。アイコンを削除して追加し直すか、初期化で tmp を選びます
自動フォルダを未設定に戻したい初期化で tmp を選びます。起動時にフォルダは自動では読みません
24 時間たったホームの案内に従い、リセットして気象をセットし直す
